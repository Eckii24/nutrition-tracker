# Nutrition Tracker

Lokales, dateibasiertes Nutrition-Tracking mit AI-gestützter Erfassung aus Bildern und Freitext.

## Ziel

Ein persönliches System, das Mahlzeiten aus Fotos oder Beschreibungen erfasst, Tageswerte für Makros/Mikros/Ziele berechnet und eine qualitative Einordnung der Ernährung liefert.
